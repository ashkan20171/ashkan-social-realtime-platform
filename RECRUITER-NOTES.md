# Recruiter Notes

Ashkan Social is intended to demonstrate practical .NET engineering rather than claim production-scale deployment.

What to review first:
- Home dashboard and reusable visual system
- Direct and group messaging workflows
- `IRealtimeClient` abstraction and SignalR server
- Service-layer separation
- Creator/community/admin workflows
- Explicit production-hardening roadmap

The repository intentionally documents limitations such as local persistence and simulated security flows instead of hiding them.
