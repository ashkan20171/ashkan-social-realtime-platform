# Stage 60 Visual Target
The user-approved visual reference is the uploaded AshkanSocial sunset glass dashboard.

Key requirements:
- Full-window scenic sunset/mountain background, but never use a screenshot containing UI as the actual background.
- Dark navy glass-like left navigation and right discovery rail.
- Wide center workspace.
- Blue/cyan primary accents with subtle purple highlights.
- Rounded translucent-looking cards, thin cool-blue borders and high contrast white typography.
- Left navigation approximately 286 px, right rail approximately 320 px.
- Home page hierarchy: search/topbar, scenic hero/greeting, quick-create actions, stories, composer, feed.
- Right rail hierarchy: online friends, trending topics, suggested communities.
- Maintain this visual language across Messenger, Profile, Communities, Creator Studio, Settings, Security and Admin.
- WinForms does not provide native acrylic blur in .NET Framework 4.8; use layered dark surfaces and scenic background to approximate glass while keeping the project stable.
